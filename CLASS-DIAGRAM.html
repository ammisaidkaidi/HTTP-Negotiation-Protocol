HTTP Negotiation Protocol — UML Class Diagram (classes & types)

All runtime classes, interfaces, type aliases and internal types of the project (v2.0.0). See also ARCHITECTURE.html for the flow diagram.

Reading notes: NegotiationClient and NegotiationServer are generic over a contract C extends ContractDefinition. ServerActionInvocation is the lazy thenable returned by server.call(). JobContext, PendingRound, ExternalCallback, Deferred, AskEntry/RunEntry are internal (not exported). AsksBuilder/RunsBuilder and the proxy types are intentionally any-typed magic proxies, typed precisely only when a contract is supplied (via AskFor/RunFor).
